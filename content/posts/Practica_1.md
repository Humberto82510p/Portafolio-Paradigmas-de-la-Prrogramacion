# Introducción

En esta práctica se desarrolló un sistema de gestión de tareas utilizando estructuras dinámicas de datos en lenguaje C++. El proyecto consistió en implementar una cola de procesos para administrar múltiples solicitudes de impresión de manera eficiente.

El programa permite almacenar información de diferentes documentos, acceder a ellos mediante funciones específicas y procesar cada tarea según las necesidades del usuario. Gracias al uso de memoria dinámica, fue posible manipular la información en tiempo real, agregando y eliminando elementos de la estructura de datos.

---

# Proyecto: Gestor de Trabajos de Impresión

## Funciones principales del sistema

- Agregar documentos a la cola de impresión.
- Mostrar el siguiente trabajo pendiente.
- Listar todos los trabajos registrados.
- Eliminar trabajos procesados.
- Administrar la memoria dinámica de manera eficiente.
